# V009：高阶实时反馈、半寻路与主动清敌

2026-11-25。V008优质数据第2轮已按用户要求正式挂载，32/32真实GPU预测核验通过。高阶反馈脚本、共享生成器、数据重建及V009配套30轮训练均完成，全部权重已下载并核验。

## 目标与实时事实

新输入契约 `combat-feedback-v9-s01`，统一目标 `safe_progress`。文本明确要求主动建立攻击机会并尽快消灭敌人。有效站定射击可保留；等待需有充能、释放时机或敌人无敌等机制依据。脚本只给事实，模型继续选择全部45个控制组合。

| 信息 | 实现 | 边界 |
| --- | --- | --- |
| 移动反馈 | 最近30帧实际路程、位移和观察到的移动输入比例 | 不把位移小自动判为撞墙 |
| 射击反馈 | 人类按键观察、AI实际输入回调生效帧数及比例 | ACK不代表生效；旧人类录像缺AI回调时保持未知 |
| 生存与进展 | 累计生命下降、可比较敌人HP变化、清房转换 | 恢复生命不抹掉已观察损失；转换/实体身份变化为未知；伤害归因未知 |
| 攻击停滞 | 连续可比较且有可伤害敌人、没有净HP进展的时间，最多60帧 | 历史断裂或实体变化重置；不称为确认没有命中 |
| 攻击几何 | 各移动后各射击方向的对齐、原始射程和地形关系 | 穿透/复杂轨迹需结合能力说明，均为估计 |
| 半寻路 | 最多3个可达清晰中心线攻击位置、路径长度、第一段路标 | 当前已知静态地图；敌人/弹幕未计入路径代价，危险单独展示 |
| 移动比较 | 9种移动后到这些攻击位置的路径代价 | 与V007相同的短期位置近似，不保证原生惯性或安全 |

寻路使用当前房间mask、碰撞格和火焰；缺少完整地图、起点无法连接或没有有效攻击位置时返回unknown。节点四邻接，第一路标不会将当前位置误报为前进方向。模型可将它用于靠近有用攻击位置，脚本不替模型选择或执行路线。

## 桥接及共享输入

桥接保存最近61帧，按需返回 `feedback_history`。反馈限定同run/room/mode的已观察连续历史，未来帧和跨房帧被排除。旧V004/V007/V008契约保留。

[features_v009.py](../src/isaac_jev/features_v009.py) 同时用于录像重建与实时推理；features.py、skill_runtime.py及独立客户端按checkpoint契约路由。挂载V009后，工具状态 `combat_feedback` 和同名日志事件可核对实际注入的反馈、路线与观测身份。V008不会使用未训练的新文本。

空间索引和地图/碰撞体缓存减少寻路开销。47个录像快照本机构建中位数约8.8ms、最高约23.1ms，不含模型/网络/调度。219项完整回归通过；后续新增诊断检查在15项反馈专项中通过，服务器15项也通过。

## 数据与训练

继续使用47个完整无伤房间的1387条优质训练示范，验证3513、测试3079不变。原人工动作标签及N→N+4对齐保持原样；新增文本及35个数值事实从原录像重建。共7979条，965维数值，逐条核对前930维与V008一致。全部提示通过3072-token预算，最长2264 tokens。新文本重新提取特征。

只对训练集应用预定反馈监督权重：521条停滞至少15帧后换位且有进展的片段，移动权重乘1.5；1220条有进展的方向攻击，射击权重乘1.3；866条有进展且较高相对效率的片段，射击权重再乘1.2。合理机制等待受保护；原验证/测试质量权重不变。这是轨迹关联监督，不是单个按键因果回报或在线RL。

从V008第2轮初始化，保留原930维归一化，新增物理缩放字段使用mean0/std1。数值塔新增列初始化为0；同一embedding及原数值输入时原头输出保持一致。主干冻结，学习率1e-4，固定30轮，每轮保存决策头和清单；按验证集选轮，测试不参与选择。
