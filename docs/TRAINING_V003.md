## 新头

```text
冻结 Qwen3.5-2B：最后有效 token 的 2048 维向量
    ↓ LayerNorm → Linear(2048,128) → GELU → LayerNorm
                                                     ┐
165 维数值 → Linear(165,128) → GELU → LayerNorm       ├ 拼接 256 维
                                                     ┘
Linear(256,256) → GELU → Dropout(0.1)
    ├ Linear(256,9)：移动
    └ Linear(256,5)：射击
```

实际可训练参数为 357518。文本与数值分别投影、归一化，减少直接将 2048 维文本与 165 维数值拼接时的尺度和容量差异。本轮不创建主动输出参数，不计算主动损失，运行时主动使用恒为 false。接口中的第三个输出仅为禁用占位值，不是可训练分支。

这是一项需要独立数据验证的设计调整，不能保证性能更好。新头的权重格式与 v002 不同，需要重训。历史仍直接注入文本，没有额外 GRU。

## 训练策略

冻结主干特征按长度分组，以 batch 16 提取；小头使用 AdamW、权重衰减 0.001、梯度裁剪 1。最多 60 个 epoch，验证 NLL 连续 8 轮没有达到 0.005 的改善时提前停止。无论停在哪一轮，导出实际验证 NLL 最低的权重。每轮记录训练指标与验证指标，以区分拟合与泛化。

模型选择使用固定 positive 条件下的观察 positive 验证子集；最终测试在选完权重后评估。当前数据仍不足以支持整局通关或强泛化的结论。

训练已完成：第 13 轮提前停止，实际最佳权重来自第 5 轮，验证选择 NLL 为 0.85443。产物已取回 `artifacts/combat-v003`，manifest 全部文件 SHA256 校验通过；主动输出参数确实不存在。

| 指标 | 验证集固定 positive | 测试集固定 positive |
| --- | --- | --- |
| 全部样本联合动作一致率 | 76.37% | 76.00% |
| 继续上一动作基线 | 76.37% | 75.00% |

不能把整体一致率当作躲避能力。用保存的冻结特征进一步核对 positive 子集：验证 144 次移动变化只预测对 2 次（1.39%），12 次射击变化为 0；测试 61 次移动变化预测对 4 次（6.56%），4 次射击变化为 0。此结果表明当前策略主要延续既有按键。下一轮应重点调整决策点/转换帧采样和训练时序，再补充独立完整局，而不是只增加 epoch。

## 网络与推理测速

网络先使用不分配 GPU 的回显进程，通过持久 SSH TCP 隧道测量，每种负载 40 次：

| 请求额外负载 | RTT 中位数 | RTT P95 |
| --- | --- | --- |
| 0 B | 1.996 ms | 5.049 ms |
| 4 KiB | 3.291 ms | 5.464 ms |
| 16 KiB | 3.815 ms | 8.392 ms |

这是往返时间，包含 SSH 与 JSON 处理，没有 GPU 推理。详细报告 `.local/network-rtt-v003.json`。训练后使用相同权重和数据做 L40S/4060 纯模型测量，以及经 SSH 隧道的真实推理请求。后者包含序列化、网络和模型，仍不包含游戏采样、特征构建和输入执行调度。

`policy_rpc.py` 仅监听 loopback，供本次测速，不向游戏发送命令。测试结束后关闭临时服务。不能把顺序少量请求的基准当作并发服务或实机清房结果。

### 完成后的推理对照

同一 checkpoint、同一数据集、按 tokenizer 长度选择相同短/中/长输入；每个案例测 5 次并报告中位数：

| tokens | 4060 本地模型 | L40S 模型 | L40S 经 SSH 隧道总响应 |
| --- | --- | --- | --- |
| 826 | 343.09 ms | 805.02 ms | 812.18 ms |
| 1352 | 528.48 ms | 818.04 ms | 812.70 ms |
| 2417 | 900.34 ms | 877.74 ms | 815.54 ms |

三列为独立运行的基准，存在测量波动，不应要求总响应列等于另一轮模型列加固定网络常数。总响应不包含游戏采样、特征构建及输入查询调度，服务器 P95 分别约为 866/886/872 ms。最终持久连接 RTT 中位数为 1.82/2.07/2.46 ms（0/4/16 KiB），16 KiB P95 约 3.50 ms；其他轮次测到 8 ms 量级 P95，也有更高的单次波动。

当前两端均提示缺少可选加速算子，所有案例都超出 200 ms 指令预算。当前服务器实现没有在典型短/中输入上带来速度优势，网络不是主要瓶颈。建议先保留本地路径，重点压缩动态文本/改进推理后端；也可评估低频语义编码与高频数值控制的分工，避免每次微操作都重新编码长文本。性能优化后再对照服务器部署；本结果不代表独占 L40S 的理论性能。

## 后续数据

冻结主干的小动作头主要需要更多游戏领域示范：不同种子、房间形状、怪物与弹幕、受伤前的决策、正确逃脱、移动/射击转换，以及独立完整验证/测试局。通用文本没有这些动作标签，直接混入动作头训练不能解决此处泛化。可逐步补充敌人机制的上下文说明，但应与实际状态和演示一致，并重提取对应特征。
