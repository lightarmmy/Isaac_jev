# V010：阶段威胁、稳定追敌路线与实际射击反馈

2026-11-25。对应用户“补上这些”：落实 V009 Boss 落地审计中的采集、语义输入、路线和训练标注缺口。

## 实现

新契约 `combat-tactical-v10-s01`，1018 维数值。前 965 维沿用 V009，新增 53 维路线/阶段事实。训练与实时推理共用 [features_v010.py](../src/isaac_jev/features_v010.py) 和 [combat_phases.py](../src/isaac_jev/combat_phases.py)。旧模型继续使用其原契约；新文本需要配套训练，不能直接包装成 V009 输入。

| 缺口 | 新反馈 | 限制 |
| --- | --- | --- |
| 已射击却显示方向未知 | 优先从同局同房的过去 AI 输入回调恢复方向，区分未查询、全部查询但未按下、冲突方向 | 不把 ACK 或待执行动作当成实际射击；人工录像只取过去按键 |
| 跳跃信息未进入主干文本 | 动画及帧、覆盖动画、NPC 阶段及持续观察时间、当前碰撞、是否可攻击 | 阶段描述依据动画名称线索，未知不自动变成安全 |
| 不知道将来落地风险 | 当前地面坐标投影、启发式不确定余量、各移动的逃离间距；同一 NPC/动画过去恢复碰撞的经验时间区间 | 首次遇见时落地时间未知；没有给所有 Boss 硬编码落地帧 |
| 把不可攻击等同于无威胁 | 当前接触碰撞和未来落地分开；不可伤害仍可能有接触威胁 | `vulnerable` 不表示玩家安全 |
| 每帧追敌路标切换/远敌无路标 | 以 60 帧为一段保留目标和攻击位，输出剩余路径、第一路标、从该段起点减少的路径长度；搜索完整已知可达图 | 超过段长、目标消失或几何失效时重选；路径仍是静态估计 |
| 空中几何标签误惩罚 | 在训练标注中排除确定不与玩家碰撞的敌人；掩码虚假的接触躲避标签，纠正其带来的稳健性降权 | 落地后恢复碰撞仍计入；标签仍为轨迹关联而非单动作因果回报 |
| 主动推进缺少监督 | 保留原人工动作；同一攻击位仍有效、路径减少且有战斗进展时提高移动监督权重 | 不奖励单纯朝敌人靠近；有效站射和机制等待仍保留 |

`EntityCollisionClass` 根据 [Isaac API 文档](https://wofsauge.github.io/IsaacDocs/rep/enums/EntityCollisionClass.html)解释：0/3 不与玩家碰撞；1/2/4 与玩家碰撞；缺失或未识别为未知。碰撞能力仍不等于已证明的伤害来源。

采集新增 `overlay_animation/overlay_frame`、`sprite_offset/position_offset`、`npc_target_position`、`observed_target_position/type`。这些是原生接口观测，不假定 NPC 目标位置就是落点，也不把渲染偏移当作真实高度。模组更新为 0.7.0、`combat_schema=3`，已安装至项目实验游戏和 dsh 的采集资产。运行中的旧游戏需要重新加载模组才能产生新字段。

桥接保留 241 个快照；V010 可读取过去最多 240 帧用于阶段经验，路线承诺最多 60 帧。未来、跨房、跨局、跨模式帧及历史断裂之前的记录不参与。路线计算移入工作线程，接收游戏帧可以继续。状态工具输出 `combat_feedback.pursuit/npc_phases`，日志事件 `combat_tactical_feedback` 带原观测身份。脚本提供事实，模型仍自由选择 45 个动作组合。
