# V008：整房无伤、少量优质数据对齐

2026-11-25。状态：筛选、S01微调30轮及核验全部完成，全部权重已下载。用户随后要求先挂新checkpoint，`combat-v008-quality-s01-epoch002`已正式挂载，32/32真实GPU预测与缓存动作一致，见[挂载核验](benchmarks/remote-service-quality-v008.json)。

## 数据筛选

用户确认保留原始人工动作，本轮采用原标签做少量优质数据对齐。审计原始封存人工录像39个来源会话，训练来源108个物理房间；56个房间具有完整连续的人工进房到清房证据，且没有记录到受伤/死亡或不明确生命变化。筛选后从47个房间保留1387条训练样本，是原14075条训练样本的9.85%。

- 任一已观察受伤、死亡、生命转换不明或AI混合战斗记录会剔除该物理房间，包括后续回访的受伤。
- 样本必须属于有完整进房到清房证据的连续战斗访问。录像中途开始、丢帧段不能作为完整无伤证据。
- 保留有可信关联进展或合理蓄力/无敌等待的片段；最小短期危险余量估计8px，走位可复现性等级至少2。估计余量不等于游戏引擎无伤保证。
- 按时间采样且保留动作切换；每房最多96条、总体上限2000条，保持房间间平衡。合法站定射击及机制等待保留。

原始验证3513条、测试3079条完整保留，包括不理想战况；未根据本轮质量筛选替换或缩小评估集合。45个动作在训练子集中均有示范，稀有动作仍然覆盖较少。质量等级参照沿用原训练集拟合结果，未从测试集拟合。

当前关联进展可包含旧弹丸或跟班贡献；现有遥测不完全提供伤害归因，因此本轮不声称每个保留按键都有直接DPS因果证据，也不声称少量数据一定能改善实机追击。

## 训练设置

从S01原最佳第1轮初始化，保留其归一化，避免小数据重新估计均值/方差改变输入含义。Qwen主干完全冻结，仍为独立移动/射击塔及训练用质量辅助头；可训练参数980225。学习率1e-4，AdamW weight decay1e-3，训练30轮且每轮保存头、配置、归一化与清单。

文本、930维数值、动作标签和N→N+4对齐保持原契约。对筛选后的所有行逐条核对父数据prompt/numeric/action/split，验证父数据及特征lineage后重排复用Qwen缓存。未重新提取相同状态的主干特征。

选用第2轮，依据原验证集的分房型质量加权NLL；测试集不参与选轮。初始化验证选轮NLL为2.4675，新候选为2.4271。

## 同一测试集的结果

| 指标 | 原S01第1轮 | 无伤优质对齐第2轮 |
| --- | ---: | ---: |
| 移动动作一致率 | 29.98% | 31.08% |
| 射击动作一致率 | 70.67% | 72.95% |
| 联合动作一致率 | 22.12% | 24.98% |
| 不移动预测比例（含射击） | 42.58% | 18.32% |
| 完全不移动且不射击 | 10.46% | 2.70% |
| 方向射击释放比例 | 18.61% | 13.77% |
| 移动NLL | 1.9073 | 1.8814 |
| 射击NLL | 0.7966 | 0.7745 |

以上是离线动作匹配与分布，方向释放对于特殊武器也可能构成攻击；不能等同于实机开火、命中、掉血、清房或追击指标。不移动比例下降本身不证明更好的规避。
